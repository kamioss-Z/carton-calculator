## GitHub Pagesへの公開手順

### 1. GitHubリポジトリを作成
1. https://github.com にログイン
2. 右上「+」→「New repository」
3. Repository name: `carton-calculator`
4. **Public** を選択（GitHub Pages無料枠）
5. 「Create repository」

### 2. ファイルをアップロード
以下のファイルを全てアップロード：
- `carton-calculator.html`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

GitHubの画面で「uploading an existing file」をクリックして全ファイルをドラッグ＆ドロップ。

### 3. GitHub Pagesを有効化
1. リポジトリの「Settings」タブ
2. 左メニュー「Pages」
3. Source: 「Deploy from a branch」
4. Branch: `main` / `/(root)`
5. 「Save」

### 4. URLが発行される（約1〜2分後）
```
https://【GitHubユーザー名】.github.io/carton-calculator/carton-calculator.html
```

### 5. 社員のスマホ・PCに配布
このURLをLINEやメールで送るだけでOK！

## ホーム画面に追加（アプリ化）

### iPhone/iPad (Safari)
1. Safariでアプリのページを開く
2. 下の共有ボタン → 「ホーム画面に追加」
3. 名前を確認して「追加」

### Android (Chrome)
1. ChromeでURLを開く
2. 「ホーム画面に追加」の通知が出る or メニューから選択

### PC (Chrome/Edge)
1. アドレスバーの右端のインストールアイコンをクリック
